# Sitio web de Jokmá

Página pública de Jokmá (una sola página, sin librerías externas): portada con Taylor, demo interactiva
"Pruébalo aquí", funciones, planes, preguntas frecuentes y las páginas legales (términos, privacidad y
licencias, que Google Play pide enlazar).

- **La demo no lleva el motor de la app.** Los resultados (resumen, preguntas, tarjetas, mapa mental y
  respuestas de Taylor) los sacó la app con 4 apuntes de ejemplo y van guardados dentro de `index.html`.
- **Taylor** es el mismo dibujo SVG de la app, con sus poses (feliz, pensando, celebrando…). Mira hacia el
  cursor y comenta cada sección.
- Para publicarla gratis: copiar el contenido de esta carpeta a un repositorio **público** y activar
  *Settings → Pages → Deploy from a branch → main / (root)*.
- Si cambian `www/terminos.html`, `www/privacidad.html` o `www/licencias.html`, hay que copiarlos aquí también.
